# 手动验收清单

自检覆盖逻辑层；以下需人眼确认（本环境无法自动化真实交互）。

## 世界
- [ ] 双击 `build/Tuanzi.exe` 能打开窗口，窗口标题为「团子 Tuanzi — 橡果小镇」
- [ ] 小团子有呼吸起伏；移动时身体上下摆动、双脚交替
- [ ] 朝左走时眼睛高光与身体朝向一起翻转
- [ ] 相机平滑跟随，走到世界边缘时不会露出边界外
- [ ] 走进池塘范围会被挡住，不能站到水面上
- [ ] 角色经过树、房屋、NPC 时前后遮挡正确

## 交互
- [ ] 靠近 NPC 按 `E` 弹出对话气泡，气泡会自动淡出
- [ ] 在空旷处反复按 `E` 能触发野生团子兽遭遇并进入战斗
- [ ] `Tab` 打开图鉴，`Esc` 或 `Tab` 关闭

## 战斗
- [ ] 开场日志显示的是实际遭遇的团子兽名字（不是其它种类）
- [ ] 技能按钮按当前伙伴的技能表生成，另有「逃跑」
- [ ] 速度快的一方先出手
- [ ] 受击方闪白、抖动，并出现伤害飘字
- [ ] 血条随伤害减少，低于 35% 变红
- [ ] 打完后回到小镇，顶部状态栏的伙伴血量与战斗中一致
- [ ] 逃跑成功/失败都有对应日志

## 存档
- [ ] 按 `F5` 提示「已存档」
- [ ] exe 同目录出现 `tuanzi_save.json`
- [ ] 关闭后重新打开，血量、等级、背包、图鉴与上次一致
