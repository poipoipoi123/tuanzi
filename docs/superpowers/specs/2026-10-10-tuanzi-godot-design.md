# 团子（Tuanzi）Godot 客户端版 — 设计规格

**日期**：2026-10-10
**状态**：阶段一已实现；本规格为阶段二、三的开发基准
**取代**：原 Canvas / 浏览器版设计（`tuanzi/docs/superpowers/specs/2026-10-10-tuanzi-design.md`）
**修订（2026-10-10）：** 用户决定引入开源素材，美术管线从纯 `_draw()` 程序化绘制改为开源像素贴图；音频仍为运行时合成。

---

## 1. 定位变更（相对原设计）

| 项 | 原设计 | 现状 |
|---|---|---|
| 运行形态 | 浏览器直接打开 `index.html` | **Godot 4.7.2 桌面客户端**，导出 Windows `.exe` |
| 渲染 | 手写 Canvas 2D | Godot `gl_compatibility` 渲染器（核显友好） |
| 语言 | 原生 ES Module JS | GDScript 4 |
| 分发 | 单文件双击 | 源码进仓库；`.exe` 走 GitHub Release 附件（>100 MB 超仓库单文件上限） |

**不变的部分**：原创致敬定位、单机、桌面端（不做移动端）、数据与逻辑分离、IP-clean 法律边界。美术自阶段二起改用许可白名单内的开源像素贴图。

---

## 2. 技术栈

| 项 | 选择 | 理由 |
|---|---|---|
| 引擎 | Godot 4.7.2 stable | 可导出桌面客户端；镜像可下载 |
| 脚本 | GDScript 4 | 与引擎同构，无编译步骤 |
| 美术 | **开源像素贴图**（许可白名单：CC0 / CC-BY 4.0 / MIT / Apache-2.0） | 2026-10-10 用户决定改用开源素材；白名单保证 IP-clean 可审阅 |
| 音频 | **运行时合成 PCM**（`AudioStreamWAV`） | 不引入自制音频文件，来源绝对可控 |
| 存档 | 便携 JSON（exe 同目录，自动回退） | 受限环境下 `user://` 不可写，会静默丢档 |
| 测试 | 无头自检 `tests/self_check.tscn` | 无需图形会话即可跑 |
| 输入 | 代码注册 `InputMap` | 避免手写 `project.godot` 的事件序列化 |

## 4. 已实现（阶段一，交付于 v0.1.0）

- **橡果小镇**：程序化绘制的地面、小径、池塘、房屋、树木、路灯、栅栏；相机平滑跟随并限制在世界边界内。
- **小团子**：呼吸、行走摆动、眨眼、朝向翻转、受击闪白的程序化动画。
- **3 位 NPC**：头顶名牌，靠近按 `E` 对话，气泡自动淡出。
- **回合制战斗**：按速度排定出手顺序、技能菜单、伤害浮动、飘字、镜头震动、受击白光、逃跑判定、回合上限 60。
- **图鉴**：已见/已收服进度、种族数值、队伍与背包。
- **存档**：便携模式 + 自动回退，`F5` 存盘，战斗结束自动存盘。
- **障碍**：池塘与房屋以椭圆阻挡，角色不可涉入水面。
- **自检**：53 项全绿，覆盖数值表、存档、伤害公式、出手顺序、世界装配、障碍、战斗全流程。

## 6. 验收标准

- [ ] 导出 `Tuanzi.exe` 双击可玩，无需安装、无需联网
- [ ] 键盘可完成**全部**操作（含战斗指令选择，不依赖鼠标）
- [ ] `self_check.tscn` 全绿且退出码 0
- [ ] 存档导出后可清档并正确导入恢复
- [ ] 所有外部素材均在 `assets/ATTRIBUTION.md` 登记，且许可证属白名单（CC0 / CC-BY 4.0 / MIT / Apache-2.0）
- [ ] 在 Intel UHD 核显上稳定 60 fps

## 7. 法律与合规边界（硬约束）

- 不使用淘米 / 摩尔勇士的任何素材、名称、角色、剧情、界面
- 不运行 Flash / SWF，不使用原版程序
- 项目名称「团子」、角色「小团子」「团子兽」均为原创
- 所有代码均为本项目原创
- 所有外部美术/音频素材必须来自许可白名单（CC0 / CC-BY 4.0 / MIT / Apache-2.0），并在 `assets/ATTRIBUTION.md` 登记名称、作者、来源 URL、许可证链接与下载日期
- **禁止** CC-BY-SA / GPL / CC-BY-NC / CC-BY-ND 等带传染性或限制性条款的素材
